# 阶段报告：RPC 临时库关闭修复

日期：2026-11-05。

`status`、`memories`、`conflicts` 改用同步局部资源包装：打开成功后无论查询成功或失败均尝试关闭一次；打开失败直接交由 RPC 外层处理。查询与关闭同时失败时保留查询异常作为 RPC 错误消息，关闭异常丢弃；仅关闭失败时返回关闭错误。单独失败标志覆盖 `throw undefined`。该方案保持 RPC 错误信封结构，故双重失败时关闭错误不会返回或记录。

独立合成测试通过 Node VM 模块替身加载实际 `src/rpc.mjs` 并捕获实际注册处理器，不加载插件入口、真实配置、真实数据库或密钥，不访问网络、不运行旧测试。共 20 个场景通过：三个分支正常、打开失败、关闭失败；每个查询点单独失败及与关闭同时失败；额外覆盖 `throw undefined`。断言关闭次数、错误消息及正常结果关键字段。测试脚本通过标准输入运行，未留持久测试文件；Node 提示 VM Modules 为实验性功能。`node --check src/rpc.mjs` 和 `git diff --check -- src/rpc.mjs` 均通过，后者提示 Git 将来可能转换换行符。

本次未验证真实 SQLite、宿主实际装配或端到端界面，也未改动向量和重排。原有其他工作区修改保持不动。
