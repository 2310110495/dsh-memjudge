# put 同步重入隔离阶段报告

## 修复

`put` 从进入到结束的完整同步生命周期设置重入标志，使用 `finally` 清理；公开方法统一包装在执行前检查标志，包括 `close`、`raw`、读取、写入与事实投影发布入口。内部调用仍使用原闭包函数，不经过公开包装。事务开始、提交和回滚包装器执行期间同样受保护，覆盖 SQLite 状态变化前后及异常清理窗口。

## 验证

运行 `node --test test/put-reentrancy-synthetic.test.mjs test/put-transaction-synthetic.test.mjs`：23 项通过。新增测试全程使用内存数据库和合成提取器；检查提取器成功/失败与 BEGIN、COMMIT、ROLLBACK 包装器前后重入，断言公开方法受阻、旧事实保留、回滚与后续访问正常。未运行默认提取器、真实配置、数据库、密钥、网络、旧入口或向量测试。

## 边界与待审

已预先取得的 `raw()` 底层连接仍可绕过公开 API 直接操作，这是现有诊断接口的信任边界，不属于此次公开方法隔离覆盖范围。`contentSnapshot` 使用默认提取器而 `buildFactsFor` 使用注入提取器，注入模式下两者语义可能不一致；该区域由其他代理处理，本次未修改。
