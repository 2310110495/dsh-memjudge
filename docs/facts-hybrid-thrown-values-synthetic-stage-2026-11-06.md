# 混合重建异常值合成测试报告

## 历史纠正

修正前，该测试的三个 `open(':memory:')` 调用均未传入 `extractL1`，`store.put(entry)` 经 `buildFactsFor` 调用了默认 `extractL1`。此前运行该测试及基于其结果的审查涉及该默认提取器；当时实际访问了哪些资源未知，不能称为隔离，也不能据此断言未接触真实配置、数据库、密钥或网络。

## 修正和验证

三个 `open` 调用均明确注入纯合成同步函数 `extractL1 = () => []`；每次 `rebuildFactsHybrid` 已明确传入合成 `extractHybrid`。审查测试实际调用路径：启动时空内存库、`put` 使用注入的同步函数，混合重建使用注入的异步函数；该测试未调用直接使用默认提取器的 `contentSnapshot`。默认提取器模块仍由 `store.mjs` 静态导入，模块加载不等同于调用默认提取函数。

在清空继承环境变量、仅保留 `SYSTEMROOT` 的环境执行：`node --test test/facts-hybrid-thrown-values-synthetic.test.mjs`。结果 7 项通过、0 项失败；仅运行该测试文件。使用 SQLite 内存库和合成数据，未主动读取真实配置、真实数据库或密钥，未主动访问网络或运行旧入口。
