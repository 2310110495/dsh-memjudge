# 0.1.2 — 记忆可观测性开发版

## 范围

- 新增五个只读视图：概览、注入正文、记忆空间、索引与生命周期、事件活动。保留原有配置/凭证/记忆管理。
- 库体占用为 SQLite 主文件 + WAL + journal（不含 shm），与每次请求注入大小不同。
- 默认注入生效上限 S 600 / D 900 / 合计 1500 UTF-16 字符；UTF-8 字节独立计量，不换算宿主 tokens。原始配置大于硬上限时，以后端生效上限显示。
- 新增 status.value.observability v1，保持原八条 fetch 路由和旧字段；观测查询仅 SELECT，不自动执行代谢/编译/清理。
- 最近一次插件生成的注入正文仅保留一份有界候选，事件仅保留最多32条元数据。正文需明确空间+会话+显式请求；不返回跨会话候选，不存原始问题或密钥。
- 修复同一会话切换 cwd 时静态前缀缓存可能沿用旧空间的边界。
- 保留 0.1.1 Windows 迁移备份 r+ / fsync / fail-closed 修复。

## 必须公开的限制

1. 当前插件设置页/侧栏挂载没有经核验的宿主当前会话身份。因此生产面板的实际注入正文和会话事件显示“暂不可用”；不会从 URL、记忆或其他会话猜测身份。后端和隔离 UI 测试覆盖身份有效时的展开行为，但不冒充现装可用。
2. 观测值仅证明插件生成字符串，不证明宿主最终发送模型的完整上下文。宿主 token 总数/剩余上下文/缓存命中没有接线，显示未提供。
3. 两个注入回调必须在同一同步装配中共享上下文对象；未完成的配对在微任务边界过期。宿主异步分离回调、运行时 refreshContext 或没有共享对象时，仅有分层事件，完整帧为空；另一个会话生成可以淘汰唯一正文候选。
4. 新观测接口默认只统计当前工作区+全局；旧管理接口原有空间枚举行为仍保留，不宣称整个旧接口已完成 ACL 重构。
5. 旧数据缺空间时迁入 global；不自动判定历史123条的项目归属，也不擅自删除或将库限额改200KB。
6. 腾讯平台完整接入、工作台文件双向同步、人工经验升全局审批未完成。本次是可观测性开发版，不是 v2 全面验收。
7. 已知旧测试 test/v2-host-wiring-rpc.test.mjs:241 的异步闭合轮自动落库断言在本次改动前已失败；不得写成全套测试通过。

## 升级与验收

独立升级包需校验已知旧版本全部文件、备份配置/旧插件/SQLite、等待客户端托盘退出后安装，不杀宿主。安装成功只代表文件校验，不代表 GUI 已加载；需重启原客户端验证。测试与演练均使用隔离临时库，不覆盖当前安装。
