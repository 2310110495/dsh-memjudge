# 混合事实重建清理契约阶段报告

- `rebuildFactsHybrid` 接纳请求前先检查连接是否处于事务，避免被拒绝请求使已接纳请求过期。
- 校验来源为 `llm`、`rules` 或 `rules-fallback`；LLM 分支逐条校验属性、值、可选实体、类型及非负安全整数偏移。可选字段仍允许省略，以兼容已有注入调用。
- 快照校验后先回滚并确认事务结束，再发布新事实。回滚抛错或静默留存事务时启用故障门；同时发生业务错误和清理错误时使用 `AggregateError` 保留二者。
- 规则回退保留现有 `BEGIN IMMEDIATE` 快照校验及回滚行为，不发布提取结果。此行为可能遭遇其他连接的写锁争用；本阶段未改变该语义，也未测量生产环境争用。

验证：仅运行 `node --test test/facts-hybrid-cleanup-contract-synthetic.test.mjs`，8 项通过。测试使用内存 SQLite 和注入的合成提取器，未使用真实配置、数据库、密钥或网络，未运行旧入口测试。测试覆盖畸形事实和来源、事务中被拒绝的并发请求、回滚静默失败及异常、与快照过期叠加的错误保留，以及两种规则来源的锁行为。未对真实 LLM 提取质量、磁盘数据库锁争用或完整插件集成作结论。
